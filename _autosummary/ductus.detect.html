ductus.detect

ductus.detect¶

The detectors – the detectors= seam. Each one turns a span into evidence.

A detector is a plain function (text, span) -> Iterator[Signal]. That is the entire interface; there is no base class and nothing to register. Four ship, all deterministic and dependency-free:

tells

Catalogue phrase matches (see ductus.tells). Finds vocabulary.

forensic

Typographic and mechanical artifacts – em dashes, mixed apostrophes, a hard line break mid-sentence, trailing whitespace. The cheapest signal in the package and often the most decisive, because these are traces of how the text was produced rather than of how it reads.

rhetoric

Sentence shapes a catalogue cannot see: the “not X but Y” antithesis, a colon introducing a three-part parallel enumeration, concession-then-pivot.

rhythm

Burstiness – the variance of sentence length. Weak evidence, and reported as weak.

Two more ship behind the [local] extra – fast-detect-gpt and binoculars, in ductus.curvature. They are registered here so they can be named, but whether they belong in DEFAULT_DETECTORS is settled by measurement, not by being new – see misc/docs/phase-1-results.md.

Adding another one – a vendor API, a supervised classifier – means writing one more function of this shape. Nothing else in the package changes.

>>> from ductus.base import Span
>>> t = "The results were not merely good, but transformative."
>>> [s.name for s in rhetoric(t, Span.of(t, 0, len(t)))]
['not-x-but-y']
>>> t2 = "It matters — a lot — and always has."
>>> [s.name for s in forensic(t2, Span.of(t2, 0, len(t2)))]
['em-dash', 'em-dash']

The registry the detectors= seam resolves names against. It holds more than the default: the model-based detectors are nameable here so --detectors fast-detect-gpt works, without being on by default. Registering is cheap – ductus.curvature imports nothing heavier than ductus.base until one of its detectors is actually called.

ductus.detect.binoculars(text, span, *, observer='distilgpt2', performer='gpt2', bands=((1.5, 0.3), (2.5, 0.45)), min_windows=6, min_tokens=16, device=None)[source]¶

Cross-perplexity of a paired observer and performer, as a standing in this text.

Where fast_detect_gpt() asks how predictable a passage is, this asks whether two closely related models are unusually unsurprised in the same places – which generalises better to generators neither model has seen.

Needs the [local] extra, and observer and performer must share a tokenizer.

ductus.detect.fast_detect_gpt(text, span, *, model='gpt2', bands=((1.5, 0.3), (2.5, 0.45)), min_windows=6, min_tokens=16, device=None)[source]¶

Conditional probability curvature, read as a standing within this document.

A passage a model finds unusually predictable compared to the rest of the document leans machine; an unusually surprising one leans human. Neither claim is absolute, and none of the paper’s benchmark thresholds are used.

Needs the [local] extra. The first call downloads and caches the proxy model; later calls on the same text cost no model time at all.

Return type:

Iterator[Signal]

ductus.detect.forensic(text, span)[source]¶

Typographic and mechanical artifacts of how the text was produced.

Several of these argue for a human, which is the point: a detector that can only ever accuse is not a measuring instrument.

Return type:

Iterator[Signal]

>>> from ductus.base import Span
>>> t = "he said\nand then left"
>>> [s.name for s in forensic(t, Span.of(t, 0, len(t)))]
['mid-sentence-newline', 'no-terminal-punctuation']
ductus.detect.rhetoric(text, span)[source]¶

Sentence shapes a phrase catalogue cannot see.

These are the patterns that survive a model being told to avoid “AI words”, which is why they matter more than vocabulary as models improve.

Return type:

Iterator[Signal]

>>> from ductus.base import Span
>>> t = "This is a pattern: you plan it, you build it, and you ship it."
>>> [s.name for s in rhetoric(t, Span.of(t, 0, len(t)))]
['colon-tricolon']
ductus.detect.rhythm(text, span)[source]¶

Burstiness: how much sentence length varies.

Uniform lengths lean machine, uneven lengths lean human. This is the weakest detector here and the thresholds come from the shared catalogue metrics, not from a fitted model – treat it as a tiebreaker, never as a finding.

Return type:

Iterator[Signal]

>>> from ductus.base import Span
>>> t = ("One two three four five six. " * 7)
>>> [s.name for s in rhythm(t, Span.of(t, 0, len(t)))]
['low-burstiness']
ductus.detect.tells(text, span)[source]¶

Catalogue phrase matches, as signals. Quoted text is skipped.

Return type:

Iterator[Signal]

>>> from ductus.base import Span
>>> t = "Let's delve into it."
>>> [(s.name, s.direction) for s in tells(t, Span.of(t, 0, len(t)))]
[('ai-vocabulary', 'machine')]
>>> q = 'Models overuse "delve", so avoid it.'
>>> list(tells(q, Span.of(q, 0, len(q))))
[]
